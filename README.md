# Tidelane — Container Shipping Management Demo

A working demo of a BuyCo-style ocean freight platform ("Master your Container Shipping") under an original neutral brand. Single-page React app with realistic, deterministic mock data — no backend, no external services.

## Modules

- **Control Tower dashboard** — KPIs (active shipments, containers in transit, on-time %, D&D cost at risk), exceptions panel, arrivals this week, recent milestone activity, weekly volume chart.
- **Shipments** — searchable/filterable table of ~40 shipments across 8 real trade lanes (Shanghai–Rotterdam, Ningbo–LA, Haifa–Hamburg, …).
- **Shipment detail** — milestone timeline (planned vs actual), containers, documents with approve action, parties, collaboration thread.
- **New Booking** — 4-step wizard (route → cargo → sailing schedule selection → review) that creates a live shipment in the app.
- **Track & Trace** — offline SVG world map with route polylines and vessel positions colored by status.
- **Documents** — cross-shipment document registry with type/status filters.
- **Analytics** — TEU volume by month, carrier allocation, on-time % vs target, CO₂ by trade lane (Recharts).

## Stack

React 19 + TypeScript + Vite + Tailwind CSS v4 + react-router-dom + Recharts + lucide-react.

Mock data is generated by a seeded PRNG (`src/data/generator.ts`) anchored to a fixed "today" (2026-08-31), so every load shows the same believable dataset. The map (`src/components/map/WorldMap.tsx`) is a hand-rolled equirectangular SVG projection — no tile servers, works fully offline.

## Run

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # type-check + production build to dist/
```

## Deploy

Live at https://yigal.effi-mor-e04.workers.dev/ (Cloudflare Workers, static assets with SPA fallback — see `wrangler.jsonc`).

```bash
npm run deploy   # build + wrangler deploy (needs `wrangler login` or CLOUDFLARE_API_TOKEN)
```
